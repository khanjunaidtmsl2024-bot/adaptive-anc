5. IMPORTANT ARCHITECTURE DISTINCTION: SPEECH ENHANCEMENT VS PHYSICAL ANC

A major conceptual issue discussed throughout the project:

Speech enhancement

The system estimates or reconstructs a cleaner speech signal from noisy microphone audio.

noisy speech → AI/DSP → cleaner speech
Physical ANC

The system creates anti-noise through a secondary acoustic path and relies on destructive interference.

reference noise → controller → loudspeaker anti-noise
                         ↓
                  acoustic cancellation

These are related but not identical problems.

The current project is best understood as a hybrid speech-enhancement + adaptive-noise-cancellation architecture, not as a claim that a neural network alone performs classical physical ANC.

This distinction must be explained clearly to judges.

12. ADAPTIVE FILTERING STRATEGY
12.1 LMS

Basic LMS:

y[n] = wᵀ[n] x[n]

e[n] = d[n] - y[n]

w[n+1] = w[n] + μ e[n] x[n]

The team should deliberately test:

too-large μ → divergence;
too-small μ → slow convergence;
filter-length changes;
varying input power;
reference correlation.
12.2 NLMS

Normalized update:

w[n+1] =
w[n] + μ e[n] x[n] /
(ε + ||x[n]||²)

NLMS is the preferred educational/reference adaptive algorithm because normalization makes it less sensitive to input-power variation than plain LMS.

12.3 Experiments that are mandatory
Make LMS diverge.
Make LMS converge slowly.
Compare LMS and NLMS under changing signal power.
Vary number of taps.
Use a good correlated reference.
Use a bad/uncorrelated reference.
Add speech leakage to the reference.
Measure speech damage.
Simulate a secondary path.
Implement/test FxLMS or FxNLMS separately.
13. CRITICAL REFERENCE-MICROPHONE ISSUE

A reference microphone is not automatically useful.

It should capture noise that is:

correlated with the noise at the primary/error location;
sufficiently ahead in time to allow cancellation;
not dominated by the user's speech.

Bad reference placement can make the adaptive filter:

fail to converge;
converge to the wrong solution;
cancel speech;
destabilize the output;
provide little improvement.

Therefore reference-mic placement is an experimental variable.

22. ANTI-ALIASING / CLIPPING DISCUSSION

A microphone or ADC chain must respect sampling theory.

Important distinction:

Digital MEMS microphone

The microphone module can contain its own analog-to-digital conversion and internal filtering.

External analog ADC

If an analog signal is sampled externally, anti-alias filtering must be handled in the analog front-end before the ADC.

Do not say:

"AI will fix aliasing."

It will not.

Similarly:

If a loud impulse clips the microphone/ADC, the missing waveform information cannot be reconstructed by AI.

Therefore measure:

microphone headroom;
ADC range;
gain;
clipping;
overload recovery;
limiter behaviour.

The project explicitly investigated commercial tactical communication hardware such as 3M PELTOR ComTac.

The key conclusion was:

"AI noise cancellation" by itself is not a defensible novelty claim.

Commercial tactical systems already provide:

hearing protection;
impulse protection;
boom-mic noise reduction;
gain/frequency profiles;
situational-awareness audio.

The stronger novelty argument is:

Commercial tactical systems:
    protection + classical/DSP processing
    + predefined/operator-selected profiles

Our proposed system:
    learned noise-aware adaptation
    + speech enhancement
    + adaptive filtering
    + impulse-aware controller
    + reference-mic information
    + runtime health/fail-safe logic
    + low-latency edge deployment

The claim must remain carefully worded.

Do not claim:

"ComTac cannot handle impulse noise."

It can.

Do not claim:

"Nobody has AI adaptive ANC."

That is too broad and likely false.

The defensible positioning is:

A low-latency hybrid AI–DSP architecture designed to automatically adapt speech enhancement and adaptive cancellation behaviour to changing and impulsive defence acoustic conditions, rather than relying only on fixed/operator-selected profiles.
